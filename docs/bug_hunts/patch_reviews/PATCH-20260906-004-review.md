## Patch summary

Added three private reusable helpers in `maintenance/dialogs.py` next to the
existing `close_coordinated_dialog`:

- `_register_coordinated_waiter` - subscribe one dialog to an in-flight shared
  scan exactly once (waiting flag, waiting status text, coordinator subscribe).
- `_start_coordinated_dialog_scan` - start or join one keyed coordinator scan:
  owner active-guard, `coordinator.run(...)`, coalesced-run waiter registration,
  owner-active transition, and owner-start UI hook.
- `_dispatch_coordinated_shared_result` - deliver one shared coordinator result
  to a waiting dialog (clear waiting, retry on `None`, else dispatch).

Migrated `ProcessDialog.refresh()` and `StorageDialog.scan()` to delegate the
owner/waiter lifecycle to the shared helper while keeping task construction,
result rendering, button state, read-only behavior, cancellation wording,
progress handling, and error wording in each dialog.

## Behavior preserved

- Operation keys and node-qualified keys unchanged (`"process"`, `"storage"`).
