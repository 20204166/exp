## Patch Summary

- Explicit transfer of existing dashboard admission to worker wrapper; launch failure
  releases admission and reports error; worker finish accounting queued to UI thread.
- Dashboard progress enters existing UI queue; hidden completion resolves lifecycle
  before deferred render. Errors resolve directly on existing delivered UI callback.
- Discovery activity cannot call after from non-main thread; existing background
  poll remains alive while discovery is active (no new per-component timer).
- Optional AppCoordinator finalizer runs on delivered physical completion including
  cancel/error; component cancellation retains admission until this callback;
  no coalesced re-admission; deferred component render cannot finish a newer run.
- Unknown pressure returns to bounded admission; valid thresholds/hysteresis retained.
  Sampler thread-start failure resets busy latch and records unavailability.
- Action replacement prunes state-update failures; Cluster dispose does not query
  widgets that may already have been destroyed by root shutdown.
- Two existing incomplete dialog test fakes repaired without changing app dialogs.

## Audit Limits and Open Risks

No evidence yet ties a particular real macOS symptom to the simulated faults.
Clock cadence uses monotonic seconds; no ns/wall-clock mixing identified.
Governor admission uses memory percent, swap occupancy percent, RSS/total byte ratio
and internal active-job counts. System cpu_percent is collected but not used to gate;
Process.cpu_percent, load average, worker/thread enumeration and queue depth are not
admission inputs. No /proc, /sys or cgroup parsing in this governor.
Swap occupancy is not paging rate; no Mac swap-policy change justified without data.
Truly hung noncooperative workers cannot be killed safely; capacity remains held.
Timeout-grace wording may overpromise physical recovery; investigate review findings.
No release/install or final safety verdict yet. Original untracked implementation plan untouched.

## Local Opposition Pass

The configured opencode opposer agents were unavailable, so no delegated opposer
reports were produced. A local adversarial review found and fixed three issues:

- Dashboard render delivery now checks scan generation and node ownership again at
  commit time, preventing delayed stale snapshots from painting after a switch.
- A component trigger during an in-flight run now records one scheduler refresh
  request instead of silently dropping it.
- Component render intents carry the AppCoordinator generation, so an older result
  cannot overwrite a newer run. Finalizers now run after result/error delivery,
  while cancellation still finalizes before any replay.

The local pass reran its targeted regression tests and all static gates; no remaining
reproduction was found in the Linux/simulated-platform environment.
